# Vocabulary is governed by discipline, not by a fixed count

ADR-0002 capped the canonical glossary at fifteen terms and required a removal for every addition. The cap did its job — it forced the argument about which terms were load-bearing and killed an eighty-term list nobody would read twice. But a fixed count is a proxy for the principle, not the principle. It would reject a sixteenth term that a real practice depends on, and accept a sixteenth term that merely displaced something equally decorative.

The rule is now: a term is canonical only if **a practice depends on it** — some step of the cycle, some seed, or some tool would be unnamed or misnamed without it. The glossary stays small enough to read in one sitting, but "small enough" is judged by that test, not by arithmetic.

**Consequences:** Sowing was promoted — the framework's defining act had no name once germination took the lifecycle slot. Grafting stays parked not because of a count but because it is a *family*: grafting without union, rootstock, and scion is a word with no usable structure, and brownfield support is not yet built. Terms may be promoted without demotion; the argument is the gate, not the number.

**Supersedes:** ADR-0002.

*Note: the grafting example in the Consequences above is superseded by ADR-0006, which redefines grafting as foreign genetics rather than brownfield.*
